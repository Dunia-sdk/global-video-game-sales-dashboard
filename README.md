📊 Sales Data Analysis & Excel Dashboard

📌 Project Overview

This project focuses on analyzing sales data using Microsoft Excel to identify business insights, monitor key performance indicators (KPIs), and support data-driven decision-making.

The project includes data cleaning, data analysis, PivotTables, PivotCharts, and an interactive dashboard with slicers.

🎯 Objectives

Clean and prepare raw sales data.

Analyze sales performance across different years and categories.

Identify sales trends and top-performing products.

Build an interactive dashboard to visualize key business metrics.

Practice essential Excel skills used in Data Analyst roles.

🛠️ Tools & Skills

Microsoft Excel

Data Cleaning & Data Preparation

PivotTables & PivotCharts

Slicers & Interactive Filtering

KPI Analysis

Data Visualization

📈 Key Analysis

The dashboard is designed to explore:

Sales performance over time.

Revenue by product category.

Top-performing products.

Sales trends by year.

Comparisons between different business segments.

📁 Project Structure

data/ — Dataset used for the analysis.

dashboard/ — Excel dashboard and workbook.

screenshots/ — Dashboard previews.

🚀 How to Use

Download the Excel workbook from this repository.

Open it using Microsoft Excel.

Navigate to the dashboard sheet.

Use the slicers to filter the data and explore the results.

Through this project, I practiced data preparation, PivotTable analysis, interactive dashboard creation, and the presentation of business insights using Excel.
